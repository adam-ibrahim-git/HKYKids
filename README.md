# HKYKids

A React front end for Heart of Kentucky Kids, a children's-education nonprofit. Four of us built it in Spring 2025 for a class, working from the client's feedback over several rounds.

The site has a resources page of cards, a bookmarks page, a side menu and a router page that collects everything in one place. It is laid out to work on phones as well as desktops.

My part: I set up the project and the first version of the code, built the router pages, and made the header text resize with the screen. My teammates [@jennanico](https://github.com/jennanico) and [@m0dileClements](https://github.com/m0dileClements) did most of the card and button styling, the color palette and the mobile layout.

To run it locally:

```bash
npm install
npm start
```

Then open http://localhost:3000.
